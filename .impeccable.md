# The Answer Engine — Design Standards

## Design Context

### Users
Small-to-medium business owners (plumbers, contractors, real estate agents, service providers) seeking visibility in AI platforms like ChatGPT, Claude, Google AI Overviews, and Perplexity. They're researching how to get cited, understand ROI, and want proof that AEO works before committing.

### Brand Personality
**Authority + Pioneering + Trustworthy**

TAE owns the "Answer Engine Optimization" category. The voice is confident, data-driven, and educational—not salesy. Visitors should feel like they're learning from AEO experts who've solved this problem at scale. The tone is direct, no fluff, premium positioning.

### Aesthetic Direction
**Dark luxury meets digital authority**

- **Primary theme:** Dark mode (command-center aesthetic, befits an "engine")
- **Color palette:** Deep dark (near-black), with bright accent (orange/gold for CTAs and accents)
- **Typography:** Plus Jakarta Sans (headings, bold, confident) + Geist Sans (body, modern, clean)
- **Movement:** Intentional animations (GSAP, scroll-triggered reveals) — purposeful, not frivolous
- **Anti-references:** Avoid generic SaaS minimalism (too boring), avoid neon excess (too gimmicky)
- **References:** Stripe (premium, dark, authoritative), Linear (clean interface design), Bloomberg Terminal (command-center data visualization)

### Design Principles
1. **Authority through clarity** — Complex AEO concepts explained simply. Clean IA, bold typography hierarchy, scannable content.
2. **Dark luxury, not dark edgy** — Dark backgrounds should feel premium and trustworthy, not aggressive. Plenty of whitespace, refined typography, high contrast for readability.
3. **Proof over promises** — Visual design supports citations, data, case studies. Graphs, testimonials, before-after proof should feel substantial, not decorative.
4. **Motion with purpose** — Animations reveal insights, highlight CTAs, respond to scroll. No movement for its own sake. Respect `prefers-reduced-motion`.
5. **Accessibility always** — WCAG AA minimum. High contrast, semantic HTML, keyboard navigation, focus management. This builds trust.

## Technology Stack
- **Framework:** Next.js 16 (App Router)
- **React:** 19.2.0
- **Styling:** Tailwind CSS v4
- **Typography:** Geist Sans/Mono + Plus Jakarta Sans + Inter
- **Animation:** GSAP + React hooks (Intersection Observer for scroll triggers)
- **Auth:** NextAuth v5 (admin panel)
- **Color mode:** System preference + manual toggle

## Component Library
- **Buttons:** Semantic, high contrast, clear focus states
- **Cards:** Subtle shadows, hover lift effects with mouse glow
- **Forms:** Accessible inputs, clear error states, success feedback
- **Navigation:** Sticky header on scroll, mobile hamburger, keyboard accessible
- **Sections:** Full-width hero, content containers (max-width 1400px), breathing room between sections
- **Animations:** Fade-in on scroll, stagger effects for lists, smooth transitions (200-400ms)

## Color Tokens
- **Background:** #0a0a0a (dark mode primary), #ffffff (light mode)
- **Foreground:** #ededed (dark mode text), #171717 (light mode text)
- **Accent (Primary CTA):** #ff6b35 or #ffa500 (orange — test both, TBD)
- **Success:** #10b981
- **Warning:** #f59e0b
- **Error:** #ef4444

## Typography Scale
- **Hero:** 2.5rem–5.5rem (fluid, h1, brand leading)
- **Display:** 2rem–3.5rem (h2, section headers)
- **Title:** 1.5rem–2.5rem (h3, subsections)
- **Body:** 1rem–1.125rem (p, readable at all sizes)
- **Small:** 0.875rem–1rem (captions, labels, secondary text)

Font families:
- **Headings:** Plus Jakarta Sans, 600 weight (semibold)
- **Body:** Geist Sans (400, 500, 600 available)
- **Mono:** Geist Mono (code, terminal-style text)

## Spacing & Layout
- **Base unit:** 4px / 0.25rem
- **Common spacing:** 8px, 16px, 24px, 32px, 48px, 64px
- **Container max-width:** 1400px (centered, padding 24px mobile → 48px desktop)
- **Section padding:** 64px–96px top/bottom (mobile: 48px)

## Motion & Easing
- **Ease-out-expo:** `cubic-bezier(0.16, 1, 0.3, 1)` — confident, energetic (hero reveals)
- **Ease-out-quart:** `cubic-bezier(0.25, 1, 0.5, 1)` — snappy (button hovers, micro-interactions)
- **Ease-in-out-quart:** `cubic-bezier(0.76, 0, 0.24, 1)` — smooth (section fades, transitions)
- **Duration:** 200–400ms (micro), 600–800ms (section reveals)

## Accessibility Checklist
- [ ] All text contrast ≥ 4.5:1 (WCAG AA)
- [ ] Interactive elements ≥ 44×44px (mobile touch targets)
- [ ] Keyboard navigation: Tab → all interactive elements
- [ ] Focus indicators: visible, on all elements
- [ ] `aria-label` on icon-only buttons
- [ ] Semantic HTML (`<button>`, `<a>`, headings in order)
- [ ] Form labels attached to inputs (`<label htmlFor>`)
- [ ] Error messages associated with inputs (`aria-describedby`)
- [ ] Animations respect `prefers-reduced-motion`
- [ ] Images have alt text (or `alt=""` if decorative)
- [ ] Videos have captions or transcripts

## Component Examples

### Hero Section
- Full viewport height (mobile: 100vh – header)
- Large, confident headline (fluid hero scale)
- Subheadline with key value prop
- Primary CTA button (high contrast, 44×44px+ touch target)
- Background: Subtle animated gradient or dot grid
- Animation: Fade-in on load, stagger text elements

### Proof Section (Case Studies / Before-After)
- Cards with clear before/after metrics
- Testimonial quotes with client name + role
- Citation counts, visibility improvements (data visualized)
- Subtle hover effects (lift, glow), not intrusive

### CTA Section
- Clear problem + solution positioning
- Form: Email, business type, territory (simple)
- Success state: Confirmation message, next steps
- Error handling: Inline validation, helpful messages

### Navigation
- Logo + nav links (responsive hamburger on mobile)
- Sticky on scroll (appears after hero)
- High contrast buttons/links
- Mobile: Full-screen menu, dismiss on link click
